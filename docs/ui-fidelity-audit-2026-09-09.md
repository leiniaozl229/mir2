# UI 复刻原因检查与实施方案 · 2026-09-09

检查基线：主仓库 `939b22c`；目标 `apps/web/play.html`、`apps/web/ui-calibration.html` 与其生产组件。用户目标按仓库现有定位解释为 **2003 国服 1.76、800×600 桌面 UI**。上一轮完成原因审计，本轮按方案落地首批修复并补充回归验证。

## 1. 结论

**本地安装包和导出的素材可以继续用于复刻。目前没有证据支持“这个客户端无法使用”的结论。** 已有资源足够校准登录、选角、主 HUD、背包和若干窗口的主要视觉元素；原端动态交互和每个控件的用途还需要补齐证据。

复刻偏差主要来自：

1. 国服底图、Crystal 布局/行为、浏览器自绘控件同时存在，版本边界和回退机制不完整。
2. 生产布局分散在 TS、CSS 和 JSON；校准页另写场景表，默认只展示静态原图，隐藏实际控件。
3. 按钮状态、物品快捷栏、窗口协作、鼠标/键盘状态机尚未完整接入。
4. 若干真实功能缺陷被常量检查、源码字符串检查和纯函数测试漏过。
5. 缺少经过同版原端确认的截图、事件时间线与视觉差分验收。

因此，继续换底图或零散调整 CSS 很难收敛。推荐保留已有资产管线、服务端与地图渲染，集中建设统一的 UI 契约、窗口/物品交互控制器，以及直接运行生产组件的校准场景。

资源验证器的边界：`tools/validate-national-ui.py` 先验证所需文件配对；传入 `--export-root` 后还会按 manifest 报告有效、空白、重复、缺失、解码失败、哈希和几何不一致帧。必需控件用途、状态语义和运行截图仍需原端证据；导出 PNG 并加载成功只完成了素材链的一部分。

导入链的三个追溯点已落地：`import-national-ui.py` 按同一目录配对 WIL/WIX，发现同名跨目录文件时报告歧义；`wil_lib.py` 在 manifest 中保留原始索引数量和 EOF/越界尾部索引；`asset-sources.json` 已补齐国服安装包→CAB→核心文件的哈希链，PNG manifest 同时保留导出索引诊断。泛化 WZL 调色板/透明处理尚有缺口，但本包使用 WIL，这些备用格式问题不能当成本次外观偏差的直接原因。

## 4. 证据和版本契约

以安装包哈希作为候选 profile 的稳定标识，在完成原端截图比对前保留“候选/待核实”标签。禁止让截图、帧号、快捷键规则分别来自不同年代却共用“已复刻”状态。

每一条设计事实至少记录：

```text
profileId / sourceSha256 / library / frameIndex / sourceByteOffset
semanticId / width / height / sourceOffset / anchorPolicy
position / drawBounds / hitBounds / zOrder / clip / blend
normal / hover / pressed / selected / disabled / animation
textBaseline / fontSpec / soundId
evidence: asset | original-runtime | period-guide | reference-code | proposed
referenceFile / timestamp / status: measured | inferred | unverified
```

`asset` 能确定图像像素和格线；`original-runtime` 确定用途、位置、热区、窗口关系和时序；同期指南作旁证；Crystal 源码提供行为实现参考；浏览器适配标为 `proposed`。无法从一张底图判断的规则必须留在待证列表。

资料交叉检查：2003 年的[操作界面说明](https://games.sina.com.cn/z/cq/2003-06-26/14765.shtml)记录了 F9/F10/F11、数字物品快捷栏、交易/组队/行会及地图入口。这是同期转载资料，适合提出校验项；其中地图限制与后期玩法存在差异，不能直接套用到所有版本。现项目小地图的 Tab 三态、全图标记、点击寻路应单列浏览器增强项，直到获得目标版本证据。该页面只用于历史交互旁证，技术实现依据来自本地代码。

## 5. 可执行的客户端取证路线

### A. 本包继续取证，优先执行

1. 保留原安装包，记录完整哈希。将 CAB/header、文件表和静态提取产物写入 `.runtime/reports/ui-fidelity-audit-2026-09-09/client/`，禁止覆盖已提取 Data。
2. 本轮已用 InstallShield 解包链列包并提取核心启动链、读取 PE 资源。下一步完整准备配置、地图、Wav、音乐，并提取/判定游标。字符串只作为线索；加壳 PE 静态导入表可能不完整，不把其表面导入项当成全部运行依赖。
3. 在独立 Windows 环境试运行相同文件集合：先使用现有 x86 Windows 测试机/虚拟机；Apple Silicon 上准备 x86 模拟环境作为后备。先验证旧图形接口能否稳定截图，再连本地测试服务。运行环境能启动不代表旧协议一定兼容。
4. 先拍登录/注册/服务器选择/选角/创建界面；能进入世界后，使用固定测试角色拍 HUD、背包、角色、NPC、买卖、仓库、修理、交易、行会和死亡界面。
5. 每项记录 800×600 原始 PNG、操作前后截图、30/60fps 无缩放录像、鼠标坐标/按键及时间戳；记录 OS、DPI、字体、显示色深、图形后端、客户端和服务端哈希。避开账号密码画面。
6. 先给取证环境 1–2 人日的兼容性探测预算；出现连接或图形问题时保存明确日志，继续 B 路线的生产 UI 工作，防止项目无限等待原端运行。

### B. 原端能启动但不能入图

继续完成认证/选角取证。对游戏内界面使用已有 WIL 帧测量、同版可信截图、同期说明与 Crystal 对应控件源码交叉验证。只对版本握手/配置适配做最小实验，避免为 UI 审查大改服务端。入图后的交互标记待确认。

### C. 原端最终无法稳定运行

1. 继续使用本包 WIL/WIX 导出结果，生成所有帧的联系表和动画预览，查找遗漏的按钮状态、对话框、图标和鼠标资源。
2. 搜集可辨认发行商/版本/分辨率的同版参考：优先同版运行录像，其次同期截图及操作手册。每份资料保存来源和时间；现代“怀旧服/1.76”宣传标签不作为年代证明。
3. 建立帧的语义标注表，原图能测量的视觉先完成；窗口初始位置、关闭顺序、双击阈值、地图模式等未知项按可运行的明确规则实现，并标成推断。
4. 缺失位图先在整个安装包、PE 资源和已有同版归档中寻找；确实缺失的小按钮可按有尺寸依据的参考逐像素重建，保留源工程和 `reconstructed` 标记。字体/声音同样逐项登记。生成图适合概念讨论，无法提供精确帧状态和热区证据。
5. 发布验收分别给出视觉已确认、行为已确认、推断、未覆盖的数量；没有原端证据的部分不标注为原版精确复刻。

以上路线共享同一前端实现，C 不需要另起一个 UI 工程。当前材料支持先走 A，同时开工统一契约和明确缺陷修复。

  stage-coordinates.ts              client/design/canvas/world 变换
  window-manager.ts                 可见性、层级、拖动、焦点、模态

迁移顺序：先提取坐标转换和修复明确缺陷，再建立 profile/frames，随后把现有 `classic-auth/hud` 接入共用控件；依次接管窗口和物品操作，最后替换 NPC/交易等内部构图。旧类可用适配器继续接协议，避免一次重写 `play.ts`。校准页与正式页只允许数据源不同，不能维护第二套皮肤、DOM 或业务交互。

严格基准模式遇到必需帧缺失时应给出具体缺项和停止该场景的验收；开发候选模式可显式回退，并显示完整 profile 状态。独立清单标识的重建资产可以使用，静默混图需要消除。

## 10. 验收矩阵与门槛

### 视觉

- 基准场景固定 800×600、角色数据、窗口位置、HP/MP/经验、聊天文本和动画帧。原端与 Web 场景必须相同；截全页不能代替游戏区截图。
- 按登录、HUD、背包、角色、技能、NPC、买卖、修理、仓库、交易等区域保存参考图/实际图/差分图；每个核心按钮覆盖正常/悬停/按下/禁用及原端存在的选中态。
- 对无缩放静态位图层要求帧与裁切一致；布局/热区/文字基线建议允许误差不超过 1 个设计像素。文字独立检查字体差异，不能把所有文字遮罩掉后宣称通过。
- 动画固定时刻或单独以帧序列比较；地图动态角色可使用有依据的动态遮罩，遮罩范围必须记录。差分阈值先用参考原端重复截图的噪声测定；SSIM 或全图相似度只能作辅助统计。
- 小屏至少覆盖 .75/.5 倍；每种倍率检查物品提示、窗边界、四角按钮和小地图目标坐标，禁止只拍缩小图。
- 桌面为精确复刻验收目标；触屏模式单独定义操作方案和完成标准，不能仅凭整体缩小认定移动端已支持。

### 交互

| 必须回归的场景 | 成功标准 |
|---|---|
| F9+F10 同开；双首饰；背包到角色拖放 | 两窗可见；指定槽正确；操作次数为 1；拒绝后可继续 |
| tooltip 实际 hover/focus，窗靠四边 | 内容和属性正确可见；不被遮挡；离开/关窗消失 |
| 拖动后 Escape、释放页面外、pointercancel、切标签页 | 没有 drop/use/equip 请求；预览和按住状态清空 |
| 仅 F8 已绑定；F1/F8 混合与未绑定技能 | 标签/按键/重登映射一致，不压缩空槽 |
| 1/.75/.5 缩放下小地图中心、四角、黑边 | 与同一世界格对应；黑边不提交移动 |
