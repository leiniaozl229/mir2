# 小地图 UI 与交互复核（2026-09-08）

## 结论

旧实现把角色周围 25×39 格的地图块和碰撞数据重新画成 120×110 像素缩略图，并把画布压进国服底部 HUD 的右侧区域。这个画面表达的是当前渲染窗口，无法表示地图全貌；地图比例、地图切换和点击坐标也缺少统一依据。

仓库已经包含原客户端 `mmap.wil` 导出的 189 张地图图像，服务端的 `Mir200/Envir/MiniMap.txt` 同时提供“地图编号 → mmap 帧”的权威映射。配置使用 1 基帧号，Web 导出库使用 0 基帧号。比奇省 `0 101` 对应 Web 第 100 帧，兽人古墓一层 `D001 1` 对应第 0 帧。

2003 年的操作界面说明把“查看地图”列为主界面功能，当时注明洞穴内可用；后续操作指南明确记录 `Tab` 在地图尺寸与关闭状态间循环。参考资料：[2003《传奇》操作界面](https://games.sina.com.cn/z/cq/2003-06-26/14765.shtml)、[操作快捷键说明](https://games.sina.com.cn/o/z/cq/2013-09-26/1751500849.shtml)、[Legend of Mir User's Manual](https://www.mirfiles.com/resources/mir2/Mir_Manual.pdf)。当前实现采用后续玩家已经熟悉的 `Tab` 循环，同时兼容鼠标按钮。

## 实现

- 独立的 `MiniMapController` 读取原始 `mmap` 帧，保持图像宽高比并把角色、玩家、NPC、怪物和掉落物投影到同一世界坐标。
- 小地图固定在 800×600 游戏区右上角，底边在主 HUD 上方；大地图覆盖主要游戏视口；关闭状态保留一个 30×30 的“图”按钮。
- `Tab` 按“小地图 → 大地图 → 关闭 → 小地图”循环。标题栏按钮提供同样的循环操作。
- 点击地图把画布坐标线性换算为地图格，进入主画布已经使用的 `clickDestination`、寻路、开门重试和服务端动作确认流程。按住 Shift 点击请求跑步。
- 没有匹配帧时显示带网格的“暂无地图资料”状态，避免用局部碰撞图冒充完整地图。
- Agent 快照公开模式、地图编号、世界尺寸、帧索引、图像 URL、绘制区域和标记。完整试玩会核对比奇与兽人古墓帧、面板边界、Tab 三态和一次真实地图点击移动。

## 验证

`npm run test:web` 覆盖索引换算、模式循环、画布坐标和黑边点击。`npm run build` 覆盖 TypeScript 与生产打包。
