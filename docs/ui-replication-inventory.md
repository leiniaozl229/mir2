# Web 客户端 UI 复刻细节清单

审计日期：2026-10-02。机器底稿：[replication/ui.json](replication/ui.json)。目标保持 **2003 国服 1.76 的 UI、输入、服务流程与视觉细节完整复刻**；本清单不以已有按钮、组件、资源数量、构建成功或历史测试数量缩小范围。原端证据缺失的功能需要继续取证，不能自行从目标中删除。

初始盘点读取生产TypeScript/HTML/CSS、content契约、网关投影、现有断言与本机Delphi参考源码；初始盘点没有操作真实浏览器、运行原客户端或执行全业务联机测试。后续批次逐项追加source_review/unit_regression与执行日志；有限联机结果只以各条live_protocol注明范围为准，不扩大为全业务或原端验收。当前源码仍有其他任务的未提交改动，本清单保留这些工作。

证据等级必须分别保留：`native_pixels` 只证明导出像素/几何；`native_runtime` 要求同版实际运行截图或时间线；`reference_source` 是参考实现，Delphi/Crystal 均未证明与国服二进制同版；`server_source` 证明服务端结果与协议；`contract` 中 proposed 属推断；`source_review`/`unit_regression`/`live_protocol`/`browser_runtime`/`visual_comparison` 各自只证明注明的范围。仅有参考源码时，状态保留部分/缺失，同版无法取得时仍登记差异与取证债务。

统一状态：`missing` 没有请求/组件/状态机中的关键实现；`partial` 已接部分路径但需求仍有明确缺口；`implemented` 需求代码已经实现，尚缺规定验收证据；`verified` 需求的全部条件，包括适用的同版运行和真实浏览器验收均有可复核证据。JSON 与 Markdown 使用同一组稳定 ID，ID 不随实现迁移而改变。后续拆分要增加子项并保留原项覆盖范围。

每个适用控件须覆盖 normal、hover、pressed、selected、disabled、等待、失败和关闭；每个业务须覆盖接受、拒绝、超时、重复输入、取消、Escape、失焦、pointercancel、断线、死亡、跨图、迟到回复以及重新打开/重登。表中验收条件是这些公共门槛的具体补充。原端没有的状态须保存不存在的证据，而不能简单写“不适用”。

## 当前最优先落地的两处缺口

1. **UI-005 / UI-007：窗口层级与输入路由。** 本轮已提取 `classic-input.ts`，按可见认证/死亡/地图就绪和服务状态阻断世界输入；服务期间仍允许 F9/F10/F11 协作窗口，Enter/Tab 留给焦点控件。`window-drag.ts` 与 `play.ts` 已按实际 zIndex/DOM 顺序关闭顶层并在打开/focus时置前；服务打开取消持续追击/移动。原参考 `DWinCtl.pas:869–875,916–964,976–1054` 的 modal-first 以及 `ClMain.pas:1471–1474` 的场景门控是参考依据，**实际顶层Escape规则、所有服务窗阻断世界的规则保持proposed**，未找到国服同版确证。本轮已修正Escape优先级：先取消背包拿取、技能目标或技能绑键编辑，不在同一按键关闭窗口；校准页已通过 Edge 实测 CSS 叠放与焦点回收，生产登录后/死亡恢复、同版 Escape 次序及背景无世界命令仍待验收。
2. **UI-037 / UI-043：NPC/服务关闭与迟到回复。** 本轮 `npc-session.ts`、`NpcConversation.cs` 与生产 `play.ts`/Gateway已接入：单调会话stamp、map校验、A/B旧展示/quote/close隔离；关闭/死亡/断线立即失效展示。fresh-map显式automatic会话0保留有效入图脚本，不用时间阈值。经济in-flight独立保留capturedstamp，晚成交继续更新库存/金币，窗口不重开；独立系统提示关闭保留底下NPC服务；NPC错误按commandType只清对应服务等待，旧stamp不影响B，初开失败释放身份。前端模块8组、纯Gateway helper6组、生产play12组、生产Gateway9组NPC回归均通过；Gateway另4组实际五秒binding回归通过。最新51/51真实协议报告另证明导师/综合商人A/B菜单、close与旧stamp/map代次拒绝；该live不含真实经济成交。真实浏览器与同版原端对照仍待验收。同NPC旧TCP没有nonce的归因限制继续登记，不将套当前stamp或FIFO称为完整归因。

## 2026-10-08：原生按钮生命周期监听合并（UI-003）

原生按钮状态绑定曾为每个按钮分别向整页注册 `blur` 与 `visibilitychange` 回调，页面长期运行并重建控件时会累积监听。现改为每个文档各注册一组监听；失焦或切到后台时遍历当前仍挂载的原生按钮，统一释放指针捕获并复位按下/悬停态。按钮重绘后仍保留原有绑定，不重复注册；触屏后鼠标移入同一按钮也会正确恢复悬停帧。

`tests/native_frame_button_regression.mjs` 验证两个按钮共用同一组文档监听，失焦后均恢复 normal 并释放各自的指针捕获，以及触屏后鼠标悬停恢复。回归使用 fake DOM，不证明浏览器绘制或同版按钮状态；UI-003 其余状态仍保持 `partial`。
