# 个人试玩档掉落优化（2026-10-01）

原先的 20 倍爆率逐条放大掉落表。祖玛教主、牛魔王等怪原表各有约 42 条必掉药水，以及整组低阶装备；放大后这些条目全部必掉，而真正稀有的装备仍只有很小概率。服务端对每条记录独立抽取，因此同一次击杀会生成大量药水和过渡装备。

现在对当前 `MonGen.txt` 会刷新的 72 种中高等级怪使用分层规则，普通低等级怪继续使用原试玩倍率。高等级怪的重复药水按价值保留：普通怪最多四条，首领最多八条。首领掉落表中的高频低阶装备组被移除，原有高阶组提高至适合单人试玩的概率；普通高级怪保留较稀有的装备组并适度提高其掉率。技能书和祝福油保留，但设置单条概率上限。若高级怪原表几乎没有装备，补入炼狱、魔杖、银蛇作为少量通用装备机会。缺少掉落文件但在地图刷新的“剧毒蜘蛛”借用月魔蜘蛛的物品池，再按本规则调整。

装备总件数下降是清除低阶填充物的结果。祖玛教主的裁决之杖等稀有武器单项概率由原试玩表约 0.33% 提升到 8%；赤月恶魔的天尊系列每件约 24%。这些是试玩平衡值，正式经典基线和上游掉落文件均未改。

优化器只使用本地物品库和怪物库导出的 [掉落目录](../content/classic-176/p0/drop-balance-catalog.json) 作分类，`scripts/drop_balance.py` 每次从上游原表重新计算，重复应用不会叠加。原表中五个不存在于当前物品库的名字（`HP强化水`、`MP强化水`、`嗜血`、`疾风神水`、`道力神水`）在这 72 张新表中跳过；它们在旧表中本来也不能生成实际物品。

当前运行环境已应用并正常重启。再次调整倍率时执行 `scripts/apply-personal-profile.py --profile content/classic-176/personal-profile.playtest.json --apply`，然后按 `scripts/run-server-native.py` 的正常停服、启动流程重载掉落表。停用 `dropBalance` 后重新应用其他个人档，会从原表还原这 72 张表。改动前的本机运行目录备份位于任务目录的 `work/MonItems-before-balance.zip`。
