# 当前 NPC 服务与城区布局（2026-10-01）

综合商人供应 40 种物品：武器、衣服、头盔、首饰，金创药、魔法药、太阳水，以及蜡烛、火把、护身符、药粉、随机传送卷、地牢逃脱卷、回城卷、回城石和卷轴包。一个商店窗口可向下翻页；同一 NPC 支持出售、普通修理和特殊修理。普通商店不再出售旧“月卡”。商品按原物品库价格结算。

区域传送员按“城镇与村庄 / 新手与沃玛 / 矿区与地牢 / 祖玛与石墓 / 赤月与封魔 / 苍月与幻境”六组提供 60 个经过地图碰撞检查的落点；每页最多六个目的地，旧客户端不会把链接绘到对话框外。苍月岛和白日门的落点已移到城区服务 NPC 附近。野外和地牢仍保留必要的原有回城向导；沃玛森林另有 `(241,300)` 世界向导及 `(241,307)`、`(256,298)` 两名森林回城员。

已撤下旧服务器的人民币奖励说明、官方举证、元宝充值、月卡说明、彩票、足球、赌场和旧收费回收入口，以及城区分散的普通商店和重复的老传送员。原店主中有十类还承担任务分支，因此改名为“任务人”，保留任务对话和奖励，但移除买卖、修理、月卡入口与货架。仓库、任务、技能导师及野外通道不在清理范围内。

运行目录可重复执行 `scripts/install-city-services.py` 更新；`scripts/install-bichon-npcs.py` 是兼容入口，执行同一安装逻辑。新增或撤下 NPC 后需通过 `scripts/run-server-native.py stop/start` 正常保存重启。2026-10-01 已在旧客户端协议中验证：比奇综合商人返回 40 种商品并成功购买回城卷；区域传送员从比奇送达沃玛森林 `(240,300)`，再由森林向导返回比奇 `(329,268)`。十个城区服务点与 60 个传送点通过地图碰撞检查，GameSrv 启动时没有 NPC 脚本错误。
