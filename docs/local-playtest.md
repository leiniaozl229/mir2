# 本地客户端试玩档（2026-09-30）

本次个人试玩档在 `content/classic-176/personal-profile.playtest.json` 中定义：杀怪经验 20 倍，怪物掉落概率 20 倍（单条规则最高 100%），并在比奇两个新手区域加入 17 条近距离刷怪配置。经典基线与上游数据不变。本机通过 `scripts/apply-personal-profile.py --profile content/classic-176/personal-profile.playtest.json --apply` 应用到 `.runtime/server/Mir200`；重复应用不会继续叠加概率或刷怪点。修改后需正常保存停服并重启 GameSrv。

测试用“回城石”是独立物品 ID 1001。`scripts/install-playtest-home-stone.py` 从现有“回城卷”（ID 38）复制外观和 `StdMode=3, Shape=3` 的回城机制；每次使用消耗一枚，返回角色绑定的回城地图与坐标。本机需指定 `--mysql-exe`，并使用 `.runtime/mysql-client.ini`；脚本可重复执行。比奇边界的技能导师以及毒蛇山谷 `(506,484)` 的试玩补给员都提供“领取回城石（3枚）”。后者与测试角色原位置相邻，便于直接试玩。

已用旧客户端协议桥实测：补给员发放回城石，使用一枚收到成功回执；断线重登后背包保留未使用的回城石。测试时曾一次发放 10 枚，验收后改成每次 3 枚并消耗多余测试石。GameSrv 启动日志确认物品库读入 1001 件物品。2026-09-30 又在窗口原版客户端里双击回城石，角色从比奇 `(643,602)` 返回当时绑定的回城点 `(289,618)`，背包物品消耗一枚；绑定点可能随试玩变化。原始 `mir.dat` 未改动。

窗口客户端双击物品原本无效：客户端收到了 `WM_LBUTTONDBLCLK`，却把 `GetCursorPos` 的屏幕坐标 `(502,131)` 当作背包坐标处理，实际点到的是 `(40,60)`。`tools/native-window-fix/cursor-draw-fix.py` 现只在已验证的双击调用点把坐标换算为窗口客户区坐标。桌面启动器 `outputs/Local-Mir.ps1` 会自动加载修复。冷启动后，已在原版客户端实测双击药水成功消耗、双击回城石成功回城。

当前运行世界在 572 张启用地图中，有 571 张存在正数量的 `MonGen.txt` 固定刷怪配置，兽人古墓一层 `D001` 没有固定刷新点。`tools/active-monster-maps.py --output <路径>` 可从当前 `.runtime` 重新生成完整 CSV。CSV 中“配置怪物数”是刷新配置的目标数量之和，不是此刻地图上的活怪数；刷新时间、怪物定义及服务器负载都会影响实际可见数量。

常用试玩区域：比奇省 `0` 有鸡、鹿和个人档新增的新手怪；沃玛森林 `1` 有半兽人、多钩猫、钉耙猫；毒蛇山谷 `2` 有虎蛇、红蛇、毒蜘蛛；盟重省 `3` 有羊、多角虫等。沃玛寺庙 `D021`–`D024`、矿区 `D401`–`D422`、祖玛寺庙 `D501`–`D505`、石墓 `D710`–`D716` 都有刷怪配置。完整地图、怪物种类和刷新数量以 CSV 为准。
