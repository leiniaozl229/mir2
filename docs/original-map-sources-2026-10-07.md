## 可重建命令

首次导入需要该对照客户端的Map目录。原始地图文件与导出资源继续被Git忽略：

```sh
python3 scripts/import-native-map-sources.py --client-map-dir /path/to/reference-client/Map
python3 scripts/prepare-runtime.py
python3 scripts/import-map-assets.py --maps-only
```

`--maps-only`只更新地图单元与来源记录，保留原有国服Tiles/SmTiles/Objects、人物、UI、物品、音效和光标库。`--map-ids 0 2 3 11 4 5`可只导出本次替代地图。`--output-root /path/to/staging`可用于隔离验证。

现有世界先正常停服、保存角色并创建备份，再执行：

```sh
python3 scripts/prepare-runtime.py --refresh-client-maps
python3 scripts/import-map-assets.py --maps-only --map-ids 0 2 3 11 4 5
```

`--refresh-client-maps`是独立操作，不能与世界刷新参数组合。它只替换契约列出的六张地图；当前文件必须为记录的旧版、原版或尚不存在，遇到其他文件会在任何替换发生前报错。世界定义、账号和存档不由这个命令更新。默认准备命令发现现有运行地图不匹配共同来源时也会停止，避免用新地图坐标生成旧碰撞世界。
