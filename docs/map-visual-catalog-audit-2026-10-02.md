# 全量地图场景可绘制性抽查 — 2026-10-02

这次审计针对“地图素材仍像碎片图”的反馈，先校正抽样点，再检查当前 Web 图层合成是否能从现有锁定资源拼出连续的游戏视口。工具为 `tools/render-map-catalog-previews.py`；报告与 572 张 800×600 预览位于 `.runtime/reports/map-catalog-previews-2026-10-02/`，每 30 张一页的总览为 `catalog-01.jpg` 至 `catalog-20.jpg`。

预览中心按证据排序：P0 世界导航 `MAPMOVE` 点、服务端 `MonGen.txt` 刷怪坐标、扩展地图声明的生成起点。没有上述位置的地图，从锁定地图分块中选择“完整、地面纹理可见、中心格可行走”的视口；这只用于视觉抽查，不是已确认的角色出生点。

初版仅按非零地图底图引用数量选窗口，因而把 D2074 带到了黑区。回查原始 Tiles.wil（SHA-256 `92dc40c4ed6ed4417daf1ae7ad753624f992a9a24e493d651cc2eebd11963f27`）确认，帧 1951–1963 本身是近乎纯黑的实色画面，解码 PNG 与 WIL 像素一致；没有证据表明是调色板或导出损坏。审计器现按实际可见地面纹理评分，并要求候选中心格可行走。D2074 的 QA 视口因此由黑区移至 `(44,38)`，显示连续石地、柱体与地面摆件；没有伪造或替换该地图资源。

本次离线合成复用了生产端的地图格距、底/中/物件绘制顺序、按地图源哈希绑定的 Tiles 与 Object 候选，并校验每个读取的地图分块 SHA。它没有原端与当前浏览器截图差分、动画时序或亮度合成验证；353 张无导航/刷怪配置地图的抽样位置仍不是已确认路线。DH02 的 8 个引用依原库越界 nil 规则跳过并保留碰撞数据。地图资源配对与原端美术差分仍是开放验收项。


## 2026-10-02 追加：整图边界与剩余占位引用

对 572 张地图的原始 12 字节格数据做了全量坐标扫描，并为含候选缺帧引用的 23 张地图生成整图总览，产物位于 `.runtime/reports/map-full-overviews-2026-10-02/`。扫描覆盖 16,907,089 个地图格；地图分块均通过文件长度与 SHA-256 核对。未解析候选索引共 91 处、分布于 23 张图，其中 85 处位于地图最左列；其余 6 处中有 4 处位于阻挡格，D423 的一处可通行格同时绘制前景物件，D701 的一处阻挡格也有前景物件。当前国服 Tiles 对这些索引提供的是 1×1 占位，锁定候选库没有同索引可见帧；未用近邻索引拼补。逐地图和坐标见 `.runtime/reports/map-unresolved-tile-locations-2026-10-02.json`，整图合成统计见 `.runtime/reports/map-full-overviews-2026-10-02/report.json`。这些占位仍是资源缺口，不能写成“全部地图无缺帧”；这批图未发现损坏或丢失的地图分块。

相机黑边已对照参考客户端规则复核：`PlayScn.pas` 按角色坐标设置 `m_ClientRect.Left/Top`，地图边界处不钳制视口；`DrawTileMap` 先把地图画布清为黑色，再只绘制地图内有效格。因此地图边缘视野外露黑属于原客户端行为，Web 继续以角色为中心是正确复刻，不应改成边界钳制。此结论来自参考源码，仍待同版原端动态截图验证。

## 2026-10-02 追加：移动视口预取边界

运行期检查发现地图渲染窗口原先按角色中心固定留 6 格后才刷新；窗口实际覆盖范围为 X 轴中心 ±12 格、Y 轴中心上方 14 格至下方 24 格，而 800×600 视口半宽约 8.33 格、半高约 9.38 格。角色持续向窗口边缘移动时，刷新会晚于屏幕边界离开已绘制区域，造成行走过程露出空白块。现在按实际视口半径和 2 格安全余量触发续载，并在世界边界处不重复请求。`tests/map_loading_regression.mjs` 覆盖横向、向上和向下越界，以及贴图延迟期间连续移动时的重绘合并；地图加载回归共 21 组通过。浏览器动态画面对照仍未完成。

同一地图加载测试还用延迟贴图复现了移动包堆积：连续收到三个新中心时，绘制队列只保留一次最新中心补绘，测试确认最终中心为 `(44,50)`，分配不超过两套视口节点。本次修改后 TypeScript 检查和完整 `test:web` 回归通过；对 `play.html` 的生产入口构建转换 743 个模块、16 秒完成，关闭公共资源拷贝以避免重复打包大型本地资源目录。浏览器动态画面对照仍未完成，静态回归不能证明原端逐像素相同。
